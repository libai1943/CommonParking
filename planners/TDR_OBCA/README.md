# TDR-OBCA: common-model static-task adapter

Runxin He, Jinyun Zhou, Shu Jiang, Yu Wang, Jiaming Tao, Shiyu Song, Jiangtao Hu, Jinghao Miao and Qi Luo, “TDR-OBCA: A Reliable Planner for Autonomous Driving in Free-Space Environment,” American Control Conference, 2021, pp. 2927–2934. [Authors' manuscript](https://arxiv.org/abs/2009.11345v2), [published article](https://ieeexplore.ieee.org/document/9483020).

This is a MATLAB/AMPL implementation of the printed temporal initialization, distance-dual initialization and reformulated nonlinear program. **It is not a port or performance reproduction of the entire Apollo driving platform.** It makes one whole-parking optimization call; road routing, perception, repeated MPC cycles, trajectory stitching and the platform's separate fallback modules are outside this static benchmark.

## Paper-to-code mapping

1. Hybrid A* provides the geometric seed. The shared rear-axle search uses the common vehicle's full steering limit, 0.2 m cells, 5-degree heading bins, nominal 0.5 m motion primitives with the shared variable-step option, 0.04 m collision checks, 0.01 m clearance, 100,000 expansions and 180 s. A failed search is reported directly.
2. Section III-A splits the seed at gear changes and solves a temporal QP in mileage, nonnegative speed and acceleration on each phase. The horizon is exactly `1.5*(vmax^2+length*amax)/(amax*vmax)`. The constant-jerk equalities follow Section V of the cited [Zhang et al. ITSC 2019 temporal formulation](https://arxiv.org/abs/2112.02133). TDR describes its version as a modified QP but does not print its weights or all modifications. Here the nonlinear centripetal terms are omitted, and the chosen objective is `sum(a^2)+sum(jerk^2)+10*sum((speed-vmax)^2)`. Each phase has exact mileage endpoints and zero endpoint speed/acceleration. Jerk is bounded by 2 m/s³ in this initializer only. The nominal temporal spacing is 0.1 s, adjusted downward to fit each exact horizon. These are disclosed initialization choices, not claimed original experiment values. Position/heading/steering are evaluated on the original analytic Hybrid A* arcs, then the complete warm start is sampled at 200 uniformly spaced times.
3. Section III-B/Eq. (5) is solved exactly using the polygon support dual. If the distance of a disjoint body/obstacle pair is `D`, a dual normal with magnitude `r` has optimal objective `r^2/beta-r*D`; hence `r=beta*D/2`. The unit support normal comes from the closest polygon pair, and its nonnegative half-space coefficients are computed by the shared `hobca.DualSeed` helper. This is an analytic solution of the same convex QP, checked independently against `quadprog`; it is not the norm-constrained H-OBCA initialization. All dual variables, including negative distance `d`, are then divided by `max(1,r)`, exactly as Proposition III.1. The missing time-index summation in the printed first term of Eq. (5) is interpreted as independent QPs for every pose/obstacle pair, consistent with its constraints and description.
4. `model.mod` implements the forward-Euler rear-axle bicycle dynamics of Eq. (2), fixed time spacing, nonnegative distance-dual multipliers, `||A'*lambda||<=1`, the normal equality and the separation equality with **negative** `d`, as in Eq. (9). The benchmark uses `d<=-0.01` for a physical clearance of one centimetre. Collision constraints apply at states 2 through 200; the initial state is fixed to the known task pose. No additional trust region, geometric obstacle inflation or continuous collision constraint is inserted into this NLP.
5. Eqs. (7)–(8) are retained: absolute state norm, consecutive-state difference, input norm, prior-cycle-input difference, terminal-state error and the sum of negative distances. **The absolute-state term is not replaced by warm-start tracking error, and the negative-distance term is rewarded rather than replaced by a nonnegative collision-slack penalty.** Later Apollo implementations differ in these respects. Global scene coordinates are preserved, so the printed absolute-state cost is coordinate-dependent. The previous MPC-cycle input is zero for this first standalone call; it is not the neighboring input within the current trajectory.

## Fixed numerical choices and benchmark adaptations

The paper does not report the objective coefficients or optimization node count. This implementation chooses 200 state nodes (199 input intervals) and scalar weights `[0.001,1,1,1,100000,1]` for the six terms listed above. The dual-QP coefficient is `beta=1`. There is no per-case parameter tuning. The endpoint heading target uses the Hybrid A* lift of the prescribed angle modulo `2*pi`.

Vehicle geometry, speed, acceleration, steering and steering-rate limits are read from the common benchmark case. The optimization variables are the five nodal states `(x,y,theta,v,phi)` and interval inputs `(a,omega)`. Forward Euler is applied to all five common differential equations, including `phi(i+1)=phi(i)+h*omega(i)`. Both endpoint speeds and steering angles are exactly zero, and both task poses are hard constraints. These are explicit whole-task benchmark adaptations to the paper's four-state/input-steering model and soft terminal cost. The original terminal cost remains in the objective and is zero on the feasible terminal state. No output steering value is overwritten after the solve.

Ipopt with MA97 solves the NLP at tolerance 1e-8, at most 2,000 iterations and 30 CPU seconds. There is one attempt, with no fallback result. Native success requires a solved status and independently recomputed equality, bound and dual residuals below 1e-6. Node feasibility does not prove feasibility between nodes. Both native failures and execution collisions are retained.

The result is a **trajectory**, with fixed timestamps and the five native node states. Acceleration and steering rate are the native interval inputs; a final zero input sample completes the public node-array format. The common evaluator uses its documented interpolation and independent continuous dynamics, not these Euler equations. Planning time includes all three stages and format conversion, rather than only the final Ipopt CPU time.

## Use and dependencies

```matlab
result = RunPlanner('TDR_OBCA',3);
evaluation = EvaluateResult(result,LoadCase(3));
```

The planner needs MATLAB Navigation and Optimization Toolboxes and the external AMPL/Ipopt runtime with MA97. The exact polygon-support helper resides in H_OBCA and is loaded by `SetupCommonParking`; its use does not run the H-OBCA planner. No external executable, license, temporary solver file or cache belongs in this folder.

Validation checks the temporal QPs and constant-jerk integration, the analytic Eq. (5) solution against independent QPs, all NLP equations and objective terms, node-body clearance, output timestamps and continuous-input ODE replay. The independent execution evaluator remains the authority for collision frames and terminal attainment; a native terminal equality does not by itself establish executed terminal attainment.
